# Getting Started

> [!NOTE]
> This documentation covers Marko 6 and the Tags API. For Marko 5, use the version selector in the bottom left or visit [v5.markojs.com](https://v5.markojs.com/docs/getting-started/).

Marko reimagines HTML as a declarative language for dynamic, reactive web applications. Nearly any valid HTML is valid Marko, extended with components, control flow, and compiled reactivity.

## Prerequisite Knowledge

Marko builds directly on core web standards, so familiarity with HTML, CSS, and JavaScript carries straight over. For foundational web guides, see [MDN](https://developer.mozilla.org/en-US/docs/Web/HTML) and [freeCodeCamp](https://www.freecodecamp.org/news/introduction-to-html-basics/).
